## 3. P0：不修就不叫"核心完全可用"

### P0-1 岗位池在生产是死的，并连带打死第 3 步（→ 工单 **T24**）
- **证据**：`apps/report/vercel.json:8-18` 两条 cron 只有 `process-job` 与 `cleanup`，**没有任何 Vercel cron 采集岗位**；岗位同步只有 GitHub Actions（`.github/workflows/jobs-sync.yml`），缺 `DATABASE_URL` secret 时自我跳过并只发 `::warning`（绿着什么都不做）。本机 `jobs stats` 实测：`total active=2303 inactive=0`，而 `last_seen_at` 停在 2026-09-14 —— `markStale` 只在 sync 里跑，所以 11 天前的岗位永远算 active。
- **最小修法（组合）**：① 部署阶段配好 Actions secret 并手动首跑一次 sync；② **报告页加"自选岗位"入口**（粘 JD → 复用既有匹配/简历链路），让第 3 步不依赖池子存活；③ 空池时改掉"在上方选择一个岗位"的文案并说明岗位库状态。

### P0-2 "失败必须显式"这条自家铁律当前不可能触发（→ 工单 **T25**）
- **证据**：`apps/worker/src/index.ts:255` 把 `status: 'complete'` 写死（`missing` 只进 `jobs.succeed`），而三处消费者按 `status === 'complete'` 判断（`apps/api/src/index.ts:668,855,1061`）→ `partial` 分支在生产不可达；报告页任何 SSR/DB 异常都 catch→null→重定向 `?notfound=1`（`pages/[locale]/report/[profileId].astro:39`、`lib/db.ts:45`），而**全仓没有任何页面读 `notfound`**（Grep 仅命中写入处）→ 数据库挂了的表象与"画像不存在"完全相同。
- **最小修法**：worker 按 `missing.length` 写 `partial`；home 区分"未找到"与"暂时不可用"。约 20 行 + 两条用例。**同一处修法顺带补上 PRD:179 / AGENTS 第 3 条承诺的 L0 早返回**（先写 `partial` L0 轻画像、L1 完成后升级为 `complete`），否则限频时用户只能干等 spinner（`AnalyzeForm` 轮询无截止时间）。

### P0-3 回访即失联（产品没有账号感）（→ 已由 **T17** 承载，评审建议提到上线前）
- **证据**：同 §2 第 5 行；`AccountMenu` 收到 `claimedProfileId` 不渲染（已登记为 T17）；匿名/demo 会话配额 3 次且 24h 过期。
- **最小修法**：T17 的"我的"页（接 `listBySubject` + 导航入口），是六步链里唯一没人写的前台入口。

### P0-4 删除与解绑只有口头承诺（→ 工单 **T26**）
- **证据**：`apps/api/src/*.ts` 中 `app.delete(` 0 命中；PRD:230 验收与隐私页承诺均无对应实现；`auth cleanup` CLI 只删过期会话与未认领闲置账号，**从不碰 profiles/evidence**。
- **最小修法**：先兑现承诺而非先做自助——一个内部运维子命令（按 profileId 删除/匿名化画像与证据 + 撤链）即可让隐私页那句话为真；自助解绑随后。

## 4. P1：不阻塞核心可用，但上线前必须知道

> 本节前两条与 `deferred-items.md` 之外的 fail-open 风险已合并立单为 **T27**（三处 fail-open 收口），不要停在"知道"。

- **匿名可消耗付费额度**：`POST /resumes/build` 无身份闸（`index.ts:1336`）且 `polish:true` 会真打 LLM（`:1383+`）。`matchRatePerHour` 在 `demo-config.ts:27,50,126` 定义、可由 env 配、有测试断言解析，**却没有任何 handler 消费它**（全仓 7 处命中全在 config/test）——这是一个"看起来有限流其实没有"的死旋钮。

- **零测试的关键模块**：`apps/api/src/github-auth.ts`、`match-explain.ts`、`auth-config.ts` 均无同名测试文件（`ls` 实测）。
