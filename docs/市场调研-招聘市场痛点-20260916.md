# 市场调研 · 中国招聘市场双方痛点（企业招聘 × 员工应聘）

- 状态：现行（2026-09-16）
- 定位：中国招聘市场 B 端（企业招聘）与 C 端（员工应聘）痛点全景：核心结论、量化证据、共同根源与对 JobAgent 的启示
- 日期：2026-09-16
- 来源性质说明：下表数字已标注来源类型——「官方/机构报告」可信度高；「行业调研/媒体转引」为一方口径，仅供参考；个别自媒体估算未采信。

## 0. 一句话结论

企业与求职者并非简单"供需失衡"，而是深陷同一套**信息不对称困局**：简历是唯一信号源，双方都信不过它——企业收到海投+造假简历难以甄别，求职者投出简历却石沉大海，平台则在两头收费中加剧错配。

| 痛点 | 关键数据 | 来源（性质） |

## 3. 共同根源（三个结构性矛盾）

1. **信息不对称是根**：简历是唯一信号载体 → 企业怕造假（32.7% 造假率倒逼背调），求职者怕被淹没（75% 沉默淘汰）——双方都在为"不可信信号"付费。
2. **平台商业模式错位**：求职者充值权益有限，企业另买曝光率，平台"两头吃"反而激励"僵尸岗位+海投"（触电新闻调查原话）。
3. **供需结构错配**：高端技工缺口 450 万 vs 应届生 1222 万挤压同质岗位，AI 岗从供不应求转向供大于求（供需比 1.08）。

## 4. 对 JobAgent 的启示

- 双方痛点的共同解是「**可信信号**」——企业要可验证的履历（对抗 32.7% 造假率），求职者要可解释的匹配与反馈（对抗 75% 沉默淘汰）。
- JobAgent 天然落在"共同根源 1"的解上：用**可验证的行为证据**（GitHub/Gitee 证据链）替代自述简历——企业端降低误聘（对应造假痛点），求职端用证据+匹配获得差异化与反馈（对应石沉大海痛点）。
- C 端"定位模糊/一稿多投"（57.6%）说明**简历生成与岗位定向**有独立价值，恰是已落地的 P-R1 定向简历功能（`design-targeted-resume-20260915.md`）的市场依据。
