- **四级判定链**（:456-468）：`insufficient_data` → `suspicious`（有 risk）→ `mixed_signals`（thinEvidence / warns≥2 无正向 / **self_pr_ratio 单条无正向**）→ `likely_authentic`。confidence 基线 0.8，risk −0.2 / warn −0.08 / 外部 +0.05~0.1，clamp 0.3–0.95（:470-482）。
- **能力标签**：language（上限 6，`skills.ts:72`）、framework/domain（目录遍历产出，上限 10/4，:297,301）+ **topics 兜底**（同一 topic ≥2 仓、depth 恒 used、置信封顶 0.6、最多 3 条、停用词表，:129-184）。
- **improvementSuggestions**：2 条规则（`no_pull_requests` / `no_external_contributions`）。
- **面试题**：5 类 kind（self_repo_depth / external_pr / high_star_design / language_depth / issue_diagnosis），取 5 条。
- **跨源融合**：共享 commit oid 判镜像（强判据，一对一合并）、仅同名报 `suspectedMirrors` 不合并（弱判据）；跨源同帖去重窗口 7 天（`fusion.ts:48`），star/fork 取 max 不相加。
- **activity.metrics**：14+ 字段，含 mergedDiffLines / largestMergedPrDiff / externalMergedPullRequests / commitRepoCount / events 三字段（条件性出现）。

### 4.2 数据采集

- **github-source**：GraphQL 主 + REST 补；预算 `{graphqlPoints:1500, restCalls:120}`（`client.ts:8-11`）；失败写 `missing`，L1 整体失败降级 L0-only；REST commit 有 ETag/304 缓存；限频退避（主限频重试<2、次级<3，不重试 4xx）。
- **gitee-source**：REST-only v5，预算 56 次（`collector.ts:40`）；`pr_code_stats` 恒缺失；events 只取一页；弱 ETag；429/5xx 退避；明文邮箱剥离。
- 两源产出同一 `AnalyzerInput`，内核无平台分支。
