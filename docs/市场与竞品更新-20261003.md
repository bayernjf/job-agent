## 0. 执行摘要

- **赛道融资显著加速**：一个月内至少 6 起 AI 招聘/求职融资（HiringCafe $6.8M pre-seed、Jack & Jill $40M A、Spott $21M A、Juicebox $36M A、Metix $5.5M、50skills $6M），且多数明确打「agentic」牌。
- **巨头入场**：LinkedIn 发布 Hiring Assistant 2（招聘方 agent，2026-09-29）；OpenAI Jobs Platform 2025-09 已宣布（预计 mid-2026，截至今日未见上线新闻）；GitHub 官方推出 Skills 技能验证徽章与 Copilot 认证体系。
- **「GitHub 行为证据」定位出现新玩家**：GotSkillz、Checkmarked、SkillMD 均以「读 GitHub 代码/活动验证技能、不要简历」为卖点——**市场验证了 JobAgent 的方向，同时竞争者在增加**。
- **对 JobAgent 的含义**：① C 端 agentic 求职（工作台→半自动投递）方向被验证且对手在加速，差异化要靠「可解释 + 可复核 + 招聘方侧信任」；② B 端不跟通用 ATS 正面竞争（巨头+融资密集区），聚焦 GitHub 行为证据这一垂直；③ 免费策略（HiringCafe 免费 AI Talent Agent）是定价压力信号，但 JobAgent 的「行为证据」供给成本天然高于自述简历产品。

> 结论：**「GitHub 行为证据评估」这一细分正从空白走向拥挤**。JobAgent 的相对优势是完整产品闭环（分析→报告→匹配→简历→求职工作台→B 端检索），而非单一验证点；相对劣势是单一开发者产品与个人项目（Checkmarked/GotSkillz）比，「开箱即用」门槛更高。

## 4. 对 JobAgent 迭代方向的含义（更新自基线 §6）

### 机会（保持/强化）
- **C 端 agentic 求职被市场验证**：工作台（阶段 1）→ 半自动投递（阶段 2）方向正确；HiringCafe 免费 agent 说明需求真实，但 JobAgent 的「行为证据」供给使推荐比「自述简历」更可信——**这是付费意愿的支点**。
- **招聘方侧「可信信号」成为巨头话术**：LinkedIn 也在讲 trusted signals——说明市场教育已完成；JobAgent 的差异化是**跨平台行为证据 + 可复核证据链**（GitHub/Gitee 双源），巨头难以短时间复制。

### 威胁（监控）
- **免费策略定价压力**：HiringCafe 免费 AI Talent Agent 无订阅墙——JobAgent 定价时需绑定「可信画像/报告」而非「自动投递」。
- **GitHub 官方 Skills**：若成规模，开发者侧「技能徽章」可能先于 JobAgent 建立心智；对策＝把 JobAgent 定位为「比徽章深一层」：可解释、可复核、可被招聘方引用。
- **B 端通用 ATS 拥挤**：LinkedIn Hiring Assistant 2 + Spott + Juicebox——JobAgent B 端应聚焦「候选人行为画像」这一层，做 ATS 的数据源/插件而非替代品。

### 跟进建议（优先级排序）
1. **P0（保持）**：求职 Agent 阶段 2 按既定边界推进（扩展自动填充 + 披露标识）；HiringCafe/Jack&Jill 的融资验证了方向，但**不改变启动条件**（阶段 1 真实使用数据 + 合规复核）。
2. **P1（防御）**：报告/工作台强调「行为证据 vs 自述」对比，把「可复核」做成面向 C 端求职者的显性卖点（对抗 GitHub Skills 轻量徽章心智）。
3. **P1（数据）**：B 端候选人侧考虑支持「GitHub Skills 徽章」作为**辅助信号源**之一（可增加证据密度，与官方徽章共存而非对抗）。
4. **P2（观察）**：OpenAI Jobs Platform 上线状态、HiringCafe 免费 agent 的留存与付费转化——影响 JobAgent 定价与 C 端功能取舍。
5. **P2（合规）**：Jack & Jill「agent 直接谈判/绕过申请」形态——监控其平台条款与监管反应，为 JobAgent 阶段 2/3 的合规边界提供参照。
