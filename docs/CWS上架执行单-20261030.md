## 3. Privacy 页签（最容易卡的环节，逐条照抄）

- **Single purpose**（英文框）：
  > JobAgent Autofill has one purpose: fill out technical job application forms on supported applicant tracking systems in one click, using the user's own evidence-verified JobAgent profile and locally stored contact details.
- **Permission justifications**：三段分别对应 `storage`、host permissions（四家 ATS 通配域）、`externally_connectable`/网络访问——**整段复制 store-assets README「Permission justifications」的英文文本**（2026-10-30 已改写为与现行 manifest 一致的精确域口径，不再有宽泛 glob，无需预答该问题）。
- **隐私政策 URL**：`https://app.job-agent.bayjf.com/en/privacy`
- **Data usage 问卷（建议答案，提交前你过目一遍）**：问卷问的是扩展是否"收集/使用"下列数据——按隐私政策的口径（联系方式只存本机、绝不上传；密码/支付不接触；不售卖、不用于广告），建议：
  - `Personally identifiable information` / `Authentication information`（扩展本机保存 JobAgent 登录令牌与联系方式）：**如实勾选**，并在下方的用途说明里写 "Stored locally on the user's device only; used solely to fill the application form the user chooses to submit; never transmitted to the developer or any third party."
  - `Website content`（content script 读取申请表单字段以填充）：**如实勾选**，用途说明同上口径（local processing, form filling only）。
  - `Personal communications`、`Health`、`Financial and payments information`：**不勾**。
  - 三个合规声明（不售卖用户数据、不用于独立于单一用途的场景、不用于评定信用/借贷）：**全部勾选 Yes/同意**。
- ⚠️ 问卷措辞以 Dashboard 实际展示为准；与 [privacy-policy-20260924.md](privacy-policy-20260924.md) 冲突时**以隐私政策为准并回头改我这份**，不要反向迁就。

## 5. 提交与审核

1. 五个页签全部绿勾后点 **Submit for review**。
2. MV3 + 精确 host_permissions（4 个通配域，无宽泛 glob、无敏感权限）是快审档，通常数小时到 3 天；若被打回，**优先看是否卡在 Data usage 问卷与申辩文本的一致性**（审核员会核对 manifest 实际声明）。
3. 审核期间保持生产 API 正常——审核员可能打开面板，空状态会引发额外人工审查（store-assets README 预检第 8 条）。
